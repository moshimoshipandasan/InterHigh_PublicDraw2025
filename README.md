# インターハイ剣道競技公開抽選システム

このプロジェクトは、インターハイ剣道競技の抽選を行うためのGoogle Apps Scriptシステムです。

## スプレッドシートへのアクセス

以下のURLからスプレッドシートのコピーを作成できます：

[インターハイ抽選（剣道競技）スプレッドシート](https://docs.google.com/spreadsheets/d/1layiZ33xHPDKjnjDu49p95tnG0tSakosp3tqYDq0vbI/copy)

## 機能一覧

このシステムでは、以下の抽選機能が利用できます：

### 基本機能
- **未抽選番号のみ抽選**: 1から48までの未抽選番号をランダムに表示
- **左サイドの抽選(1-24)**: 1から24までの未抽選番号をランダムに表示
- **右サイドの抽選(25-48)**: 25から48までの未抽選番号をランダムに表示

### ゾーン抽選
- **第1ゾーン抽選(1-12)**: 1から12までの未抽選番号をランダムに表示
- **第2ゾーン抽選(13-24)**: 13から24までの未抽選番号をランダムに表示
- **第3ゾーン抽選(25-36)**: 25から36までの未抽選番号をランダムに表示
- **第4ゾーン抽選(37-48)**: 37から48までの未抽選番号をランダムに表示

### リーグ抽選
- **Aリーグ抽選(1-3)**: 1から3までの未抽選番号をランダムに表示
- **Pリーグ抽選(46-48)**: 46から48までの未抽選番号をランダムに表示
- **Hリーグ抽選(22-24)**: 22から24までの未抽選番号をランダムに表示
- **Iリーグ抽選(25-27)**: 25から27までの未抽選番号をランダムに表示
- **H&Iリーグ抽選(22-27)**: 22から27までの未抽選番号をランダムに表示

### その他
- **デモ**: 1から48までの番号をランダムに表示（デモンストレーション用）

## 使い方

1. 上記のリンクからスプレッドシートのコピーを作成します
2. スプレッドシートが開いたら、上部メニューの「インターハイ抽選（剣道競技）」をクリックします
3. 実行したい抽選機能を選択します
4. 抽選結果が「抽選」シートに表示されます
5. 抽選結果から選択したセルの値は「抽選順一覧」シートに自動的に記録されます

## 注意事項

- 抽選済みの番号は「抽選順一覧」シートのA列に記録されます
- 各抽選機能は、すでに抽選済みの番号を除外して抽選を行います
- 抽選結果のセルをクリックすると、その番号が抽選済みとして記録されます
